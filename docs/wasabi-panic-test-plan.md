# わさびパニック — リリース前テスト計画

ルールの正は [`wasabi-panic-chef-plan.md`](./wasabi-panic-chef-plan.md) の §8。  
見た目の好みはブロッカーにしない。依頼されていないプレイ数値は試験のために変えない。

実施は **`npm run preview`（本番相当）を優先**する。`npm run dev` は HMR 用で、最終確認に使わない。

失敗したら「手順・環境・期待・実際」を残す。

---

## 方針

- **手動が本体**。描画・タッチ・実機ブラウザは目視する。
- **自動は壊れると致命的なルールと、ビルドの煙**だけ。キャンバスの E2E はしない。
- 自動: `npm test`（Vitest）。煙: `npm run build`。

実施順:

1. `npm test` と `npm run build`
2. preview で P0（PC Chrome）
3. 実機 2 系統で操作・音・FIT
4. 必要なら P1 を直して P0 を再確認

---

## 環境マトリクス

必須（各 1 台で P0 を一通り）:

- [ ] デスクトップ Chrome
- [ ] iPhone Safari（実機。音声とタッチ）
- [ ] Android Chrome（実機または同等）

余裕があれば:

- [ ] デスクトップ Firefox または Safari
- [ ] 本番と同じ置き方（GitHub Pages 等のサブパス）。`base: "./"` で画像が解決すること
- [ ] 飛行機モード相当でタイトル文字（Google Fonts 失敗時もプレイ不能にしない）

## P0 ブロッカー

1つでも落ちたら出さない。

### 画面遷移

- [ ] 起動（Boot）→ タイトル → スタート → プレイ
- [ ] クレーム 3 回でゲームオーバー → 「もういちど」でタイトル
- [ ] 2 周してもスコア・ライフ・皿が初期化される
- [ ] タイトルに属性選択（子供／大人）が残っていない

### 操作

- [ ] マウスだけで最後まで遊べる
- [ ] スマホ実機で下部 3 ボタンが押せる
- [ ] 誤タップでブラウザ戻る・ピンチズームしない
- [ ] 連打しても出荷クールダウン（160ms）とレーン上限（8 皿）で破綻しない
- [ ] ゲームオーバー後は出荷ボタンが無効

### ルール

- [ ] 開始時は 1 席だけ客。最大 4 席。満席中は入店しない
- [ ] フキダシのわさび量と、客が取る皿が一致する
- [ ] 不一致の皿は素通りする
- [ ] 右端破棄はスコアもライフも変わらない
- [ ] 同じ注文が複数席なら、皿が先に着いた席が取る
- [ ] 我慢切れで退席、スコア -150（0 未満にならない）、コンボリセット、クレーム -1
- [ ] 「繁忙!」が出る（目安: 開始約 20 秒）

### 表示・アセット

- [ ] `__MISSING`（黒い四角・緑枠・緑斜線）がない（背景・レーン・職人・客・皿・わさび）
- [ ] タイトル・プレイ・ゲームオーバーの日本語（ひらがな・カタカナ・漢字）が欠けず、□で表示されない。Google Fonts が読めなくても、端末の日本語フォントで文章が追える

### 音

- [ ] スタート（または最初のボタン）のタップ後に SE が出る
- [ ] リロード直後の無操作では鳴らない／鳴ってもエラーにならない
- [ ] 端末ミュートでも最後まで遊べる

### ビルド

- [ ] `npm test` が通る
- [ ] `npm run build` が通る
- [ ] `npm run preview` で画像パスが 404 にならない

## P1 品質

できれば直してから出す。

- [ ] コンボ表示が x1〜x5 で止まる
- [ ] 早出しでボーナスが乗る感がある
- [ ] 子供客と大人客の見た目が区別でき、注文フキダシが読める
- [ ] 職人・客・スコア皿・ボタンが重なって押せない／読めない箇所がない
- [ ] ウィンドウを小さくしても `Scale.FIT` で全体が見える
- [ ] PC の `1` `2` `3` と `←` `↓` `→` が 3 ボタンと同じ
- [ ] SE 連打で割れない・止まらない。繁忙開始の音が分かる
- [ ] タブを裏に 30 秒置いて戻しても続行できる（一気に退席しすぎないかは観察）

## P2 あるとよい

- [ ] 横持ちスマホ・デスクトップ・タブレットで 1 分遊べる
- [ ] 5 分プレイでフレームが落ち続けない、操作不能にならない
- [ ] README のスクショが現行画面と食い違っていない

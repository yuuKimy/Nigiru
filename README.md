# わさびパニック

日本の回転寿司をテーマにした、カジュアルなタイミングゲームのプロトタイプです。  
職人になって、お客の注文どおりのわさび量で寿司を握り、レーンへ流しましょう。

## ゲーム概要

プレイヤーは職人です。席にお客が増えていき、それぞれがわさびの量を注文します。

| 注文 | 出す寿司 |
| --- | --- |
| なし | わさびを載せない |
| 普通 | わさびを少し載せる |
| 大盛り | わさびを大きく載せる |

レーンを流した寿司は、注文が一致したお客だけが取ります。我慢できなくなったお客は退席し、スコアが減ります。

## 遊び方

1. `npm run dev` で起動し、ブラウザでゲームを開く
2. タイトルで **スタート** を押す
3. 下の3ボタン（なし／普通／大盛り）をタップして握り、レーンへ流す
4. クレーム（ライフ）が 0 になるとゲームオーバー。リトライでタイトルに戻る

### ルール

| 結果 | 内容 |
| --- | --- |
| 注文どおりの皿を客が取る | スコア加算（コンボで倍率アップ、早いほどボーナス） |
| 違う量の皿 | 素通り（ペナルティなし） |
| 我慢ゲージ切れで退席 | スコア -150（0が下限）、コンボリセット、クレーム -1 |

### ゲーム要素

- **席** … 最大4席。時間とともに客が増える
- **我慢ゲージ** … 客ごとに減る。尽きると退席
- **コンボ** … 連続正解で得点倍率が上がる（最大 ×5）
- **繁忙波** … ときどき入店が速くなり、大盛りが増える
- **効果音** … 握る・入店・正解・退席・繁忙など（Web Audio による合成音）

## 技術スタック

| 種別 | 技術 |
| --- | --- |
| 言語 | TypeScript |
| バンドラ / 開発サーバ | Vite |
| ゲームエンジン | Phaser 3 |
| 描画 | Phaser スプライト（Gemini で生成した寿司・UI 画像） |
| 効果音 | Web Audio API |

画面サイズは **800×600** 固定です。

ゲーム素材は Gemini の画像生成機能を利用して作成しています。

## はじめ方

```bash
npm install
npm run dev
```

ブラウザで表示された URL（通常は `http://localhost:5173/`）を開いてください。

### その他のコマンド

```bash
npm run build    # 本番ビルド
npm run preview  # ビルド結果の確認
```

## ディレクトリ構成

```
    audio/
      SoundFx.ts          # 効果音
    orders.ts             # わさび量・客の注文
    theme.ts              # フォント

  images/                 # README 用スクリーンショット
scripts/
  capture-screenshots.mjs # 画面キャプチャ用スクリプト
```

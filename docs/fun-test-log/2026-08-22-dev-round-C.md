## 時系列メモ（設計意図 vs 観察）

| 時刻 | 設計上の状態 | 観察 |
| --- | --- | --- |
| 0〜15s | 1 席。入店 5s 間隔 | 操作量は少ない。タップ待ちが続く。**序盤テンポはやや緩い** |
| 15s 前後 | 2〜3 席（退席なし理想） | フキダシが増え、判断対象が出始める |
| 20s | 初回 **繁忙!**（12s）入店 1.7s、我慢 11.2s | 明確な難易度スパイク。SE・表示で区切りが分かる |
| 20〜32s | 繁忙中 | 満席 4 になりやすい。複数ゲージ同時減少 → **パニックピーク候補** |
| 32〜52s | 通常に戻る（入店 ~4.5s） | 一息つける。繁忙の「波」が機能している |
| 60s 前後 | 3 席以上が定常、入店 ~3.7s | レーン上に不一致皿が溜まりやすい。頭の整理が必要 |
| 90s | 入店間隔が底（2.4s）に近い | 90s 以降は常に「後半」難易度。30s より明らかに忙しい |
| 52s, 84s… | 2 回目以降の繁忙 | 32s 周期で繰り返し。学習後は「そろそろ繁忙」と予測可能 |

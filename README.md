# わさびパニック

日本の回転寿司をテーマにした、カジュアルなタイミングゲームのプロトタイプです。  
職人になって、お客の注文どおりに寿司を握り、レーンへ流しましょう。マグロはわさび量、たまごはネタそのものが注文です。

## ゲーム概要

プレイヤーは職人です。席にお客が増えていき、注文は **マグロ（わさび量）** か **たまご** です。

| 注文 | 出す寿司 |
| --- | --- |
| なし | マグロ・わさびなし |
| 普通 | マグロ・わさび普通 |
| 大盛り | マグロ・わさび大盛り |
| たまご | たまご（わさびなし） |

レーンを流した寿司は、**ネタとわさび量の両方** が一致したお客だけが取ります。違うネタや量の皿は素通りします。我慢できなくなったお客は退席し、スコアが減ります。

### お客の我慢とお怒り

各客には我慢ゲージがあります。時間とともに減り、色が変わります。

| ゲージ | 目安 | 様子 |
| --- | --- | --- |
| 緑 | 余裕あり | 通常 |
| 黄 | 半分以下 | 耳付近に怒りマーク |
| 赤 | 残り少 | 怒りマーク＋客が小刻みに揺れる |

ゲージが尽きると退席します。

## 遊び方

1. `npm run dev` で起動し、ブラウザでゲームを開く
2. タイトルで **スタート** を押す
3. 下の **4 ボタン**（なし／普通／大盛り／たまご）をタップして握り、レーンへ流す
4. クレーム（ライフ）が 0 になるとゲームオーバー。リトライでタイトルに戻る

PC では `1` `2` `3` `4` または `←` `↓` `→`（たまごは `4`）でも操作できます。

### ルール

| 結果 | 内容 |
| --- | --- |
| 注文どおりの皿を客が取る | スコア加算（コンボで倍率アップ、早いほどボーナス） |
| ネタまたはわさび量が違う皿 | 素通り（ペナルティなし） |
| 我慢ゲージ切れで退席 | スコア -150（0が下限）、コンボリセット、クレーム -1 |

### ゲーム要素

- **席** … 最大4席。空席は椅子が見える。時間とともに客が増える
- **我慢ゲージ** … 客ごとに減る。黄で怒りマーク、赤で客が揺れる。尽きると退席
- **たまご** … 注文の約 25%。専用ボタンで出す（マグロの「なし」とは別）
- **コンボ** … 連続正解で得点倍率が上がる（最大 ×5）
- **繁忙波** … ときどき入店が速くなり、大盛りが増える
- **効果音** … 握る・入店・正解・退席・繁忙など（Web Audio による合成音）

## 技術スタック

| 種別 | 技術 |
| --- | --- |
| 言語 | TypeScript |
| バンドラ / 開発サーバ | Vite |
| ゲームエンジン | Phaser 3 |
| 描画 | Phaser スプライト（Gemini で生成した寿司・UI 画像） |
| 効果音 | Web Audio API |

画面サイズは **800×600** 固定です。

ゲーム素材は Gemini の画像生成機能を利用して作成しています。

## はじめ方

```bash
npm install
npm run dev
```

ブラウザで表示された URL（通常は `http://localhost:5173/`）を開いてください。

### その他のコマンド

```bash
npm run build    # 本番ビルド
npm run preview  # ビルド結果の確認
```

```
      GameScene.ts        # プレイ本体
    audio/

    orders.ts             # 注文抽選（マグロ・たまご・わさび量）
    theme.ts              # フォント

scripts/
  capture-screenshots.mjs # 画面キャプチャ用スクリプト
```
